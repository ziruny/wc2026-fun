# wc2026-fun

2026 世界杯模拟器 — 基于 FC26 球员数据的蒙特卡洛比赛模拟

## 这是什么

一个纯前端的世界杯模拟器，用真实球员数据 + Poisson 分布 + 蒙特卡洛方法，模拟 2026 年美加墨世界杯的完整赛程。

你可以：
- 点击"开始模拟"，看 AI 怎么预测这届世界杯
- 换个随机种子，看看平行宇宙里的世界杯会怎样
- 调整蒙特卡洛次数，看 1000 次和 10000 次模拟的概率差异
- 点击每场比赛，看进球时间线和进球者

## 数据来源

- **球员数据**：EA FC26 球员评分（六维属性：pace/shooting/passing/dribbling/defending/physic）
- **大名单**：2026 世界杯 48 支球队官方大名单（数据来自维基百科：https://en.wikipedia.org/wiki/2026_FIFA_World_Cup_squads）
- **对阵表**：FIFA 2026 官方 48 队赛制对阵表

## 技术栈

- React + Vite
- 纯前端，无需后端服务
- 所有计算在浏览器端完成


## 模拟模型

- **实力计算**：六维属性加权（按位置分配权重）+ 明星球员加成
- **战术风格**：从球员数据自动推导（高位逼抢/控球/防守反击等）
- **比赛模拟**：Poisson 分布生成进球数，实力差距放大系数 0.06
- **爆冷机制**：弱队有小概率额外进球（斗志因子）
- **疲劳系统**：加时赛后下一场状态下降
- **进球时间线**：按概率分布分配进球时间，按位置+射门属性选进球者

## 声明

这是一个娱乐性质的模拟项目，结果不代表真实比赛预测。球员数据来自 EA FC26 游戏，仅供参考。

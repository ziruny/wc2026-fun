# wc2026-fun

2026 世界杯模拟器 — 基于 FC26 球员数据 + Poisson 分布 + 蒙特卡洛聚合

## 这是什么

一个纯前端的世界杯模拟器，用真实球员数据 + 概率模型模拟 2026 年美加墨世界杯的完整赛程。

输入一个随机种子，模拟出一届完整的世界杯——小组赛、淘汰赛、决赛，每场比赛有比分、进球者、进球时间。换一个种子，冠军可能就换一支队。跑几千次蒙特卡洛模拟，看每支球队的夺冠概率分布。

## 数据来源

- **球员数据**：EA FC26 游戏球员评分，六维属性（pace/shooting/passing/dribbling/defending/physic）
- **大名单**：2026 世界杯 48 队官方大名单，来自[维基百科](https://en.wikipedia.org/wiki/2026_FIFA_World_Cup_squads)
- **对阵表**：FIFA 2026 官方 48 队赛制对阵表
- 1247 名球员，76% 匹配到 FC26 真实数据，未匹配球员用位置均值填充

## 模拟模型

### 球队实力

六维属性按位置加权：
- 前锋有效评分 = pace×0.2 + shooting×0.3 + passing×0.15 + dribbling×0.2 + defending×0.05 + physic×0.1
- 后卫有效评分 = pace×0.15 + shooting×0.05 + passing×0.15 + dribbling×0.10 + defending×0.40 + physic×0.15
- 前 3 球星有额外加成（平均 effective rating 超过 80 的部分 ×0.5）

### 比赛模拟（指数平滑多因子模型）

```
xG = 1.3 × exp(Δskill × 0.04) × (1 + homeBoost) × (1 + motivation)
```

- **基准进球** 1.3：国际比赛单队场均进球
- **敏感度 c = 0.04**：实力差 16 分 → 期望进球 ×1.90，强队优势明显
- **主场乘数**：东道主 +12%，客场对东道主 -6%
- **主场乘数**：东道主 +12%，客场对东道主 -6%
- **斗志乘数**：首战弱队 +8%，生死战 +12%，淘汰赛 +5%
- 进球数从 Poisson(xG) 分布采样

### 其他机制

- **战术风格**：从球员数据自动推导（高位逼抢/控球/低位防守/直接进攻/均衡）
- **疲劳系统**：加时赛后下一场攻击力下降
- **进球时间线**：按概率分布分配进球时间（76-90 分钟最多），按位置+射门属性选进球者
- **可播种随机数**：Mulberry32 PRNG，同一种子结果完全一致
